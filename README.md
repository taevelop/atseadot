# At Sea :: dot PARTY

Canvas 2D로 만든 픽셀 아트 잠수·낚시 게임입니다. 프레임워크, 서버 API, 환경 변수 없이 실행하는 정적 사이트입니다.

## 폴더 구조

```text
site/
  index.html             # 게임 진입점
  404.html               # 없는 주소의 안내 화면
  _headers               # 정적 자산 응답 헤더
  _redirects             # 기존 /atseadot.html 주소를 /로 연결
  apple-touch-icon.png   # Apple 홈 화면 아이콘 (180px)
  site.webmanifest       # Android 앱 이름·아이콘·시작 주소
  assets/
    css/style.css        # 화면 스타일
    js/game.js           # 게임 로직, 픽셀 도안, 번역 데이터
    fonts/                # Galmuri11 웹폰트와 OFL 라이선스
    favicon.svg
    icon-maskable.svg    # Android 마스크 적용용 원본
    icons/               # Apple·Android 기기별 PNG 아이콘
scripts/
  generate-icons.mjs     # SVG 원본에서 PNG 아이콘 재생성
package.json             # 로컬 실행·검증·배포 명령
package-lock.json         # Wrangler 의존성 버전 고정
wrangler.jsonc           # Workers 정적 자산 프로젝트와 배포 폴더 설정
.node-version            # Node.js 24
```

루트의 `atseadot.html`은 비교용 원본입니다. `.gitignore`로 제외했으며 배포 폴더에도 포함하지 않습니다. 이후 게임 수정은 `site/`에서 진행합니다.

## 로컬 실행

Node.js 22 이상이 필요하며, 이 프로젝트의 기본 버전은 Node.js 24입니다.

```sh
npm ci
npm run dev
```

브라우저에서 <http://127.0.0.1:8788>을 엽니다. Wrangler가 Workers Static Assets의 정적 파일, 리다이렉트, 응답 헤더를 함께 실행합니다. 로컬 실행에는 Cloudflare 로그인이 필요하지 않습니다.

```sh
npm run build
```

별도의 번들 생성 과정은 없습니다. `build`는 JavaScript 구문 검사와 회귀 테스트를 실행하며, 배포 결과물은 이미 준비된 `site/`입니다. 테스트만 실행할 때는 `npm test`를 사용합니다.

## 한글 픽셀 글자

[Galmuri11](https://github.com/quiple/galmuri) 폰트를 프로젝트에 포함해 기기에 설치된 글꼴과 관계없이 한국어·영어 UI에 같은 크기의 글자를 표시합니다. 원래 격자인 12px를 기준으로 그리며, 작은 글꼴의 번짐을 줄이기 위해 3배로 그린 뒤 픽셀 중심을 샘플링합니다. 최초 폰트 로딩은 최대 2초 기다리고, 지연되거나 실패하면 기본 글꼴로 게임을 시작합니다.

Retina 화면에서도 게임 픽셀을 정수 배율로 확대하며 입력 좌표를 같은 배율로 변환합니다. 한글 줄 간격을 확보하고, 긴 기록은 의미 단위로 줄바꿈합니다. 폰트 출처, 모바일 미리보기와 검증 범위는 [검증 문서](docs/verification.md#모바일-한글-픽셀-글자)에 정리했습니다.

## UI 크기와 조작키 표시

메뉴·기록·HUD·대사·도감·조작법은 게임 장면과 별도의 Canvas 배율로 그립니다. 402px 폭·픽셀 비율 3의 모바일에서는 UI가 약 17% 작아지고, 메뉴 폭은 282px에서 235px로 줄었습니다. 글꼴 자체는 12px 원래 격자를 유지하며 UI도 물리 픽셀의 정수 배율로 확대합니다. 이미 1배로 표시되는 작은 화면은 가독성을 위해 더 줄이지 않습니다.

Z·Enter·Space·방향키 등 조작 안내는 밝은 테두리와 아래 그림자가 있는 키캡으로 표시합니다. 키캡을 포함한 문장은 키가 중간에 잘리지 않게 줄바꿈하고, 대사창 높이는 실제 줄 수에 맞춥니다. 모바일 다이얼은 124px, 액션은 74px, 가속은 52px이며 DOM 버튼의 터치 영역은 44px 이상을 유지합니다.

한국어·영어는 같은 12px 글꼴, 14px 줄 간격, 16px 메뉴 행과 44px 수심계 폭(논리 픽셀)을 사용합니다. 메뉴와 기록 패널은 두 번역이 들어갈 공통 크기로 계산하고, 영문 메뉴 문구도 축소된 폭에 맞춰 간결하게 표시합니다. 언어 전환으로 메뉴·HUD·터치 조작부 크기가 바뀌지 않습니다.

최신 화면과 검증 범위는 [UI 크기·키캡 검증](docs/verification.md#ui-크기와-키캡-표시)에 정리했습니다.

## 게임 조작과 저장

제목 화면은 메뉴를 직접 클릭하거나 방향키와 Enter로 선택합니다. 화면 너비가 1024px 이하인 모바일·태블릿 크기에서만 화면 아래에 가상 다이얼과 액션 버튼이 표시됩니다. 1025px 이상에서는 터치 지원 여부와 관계없이 숨깁니다. 왼쪽 다이얼을 밀어 8방향으로 이동하고, 바깥쪽으로 더 밀면 가속합니다. 오른쪽의 큰 액션 버튼은 손가락이 닿는 즉시 작동하므로 이동과 포획을 두 손가락으로 동시에 조작할 수 있습니다.

플레이 화면 아래 한 줄에는 방향키 대신 창을 여는 열쇠를 적습니다. `[A]` 수족관, `[S]` 상점, `[T]` 하늘이며, 자리가 좁아지면 역할 전환과 역할별 조작부터 줄이고 가장 좁은 화면에서는 키캡 석 장만 남깁니다. 시작 메뉴도 각 행에 해당 단축키를 키캡으로 표시하고, 언어 전환은 맨 아래 행입니다.

문자 단축키는 영문 입력 기준입니다. 이동은 방향키이며 `A`는 수족관, `S`는 상점, `G`는 도감입니다. `W/D`는 사용하지 않습니다. `Q/E`는 페이지 이동에만 사용하고, 포획이나 창 닫기에 사용하지 않습니다. 거래 확인 중에는 확인·수량 변경·설명 스크롤·취소만 처리합니다.

`Space`와 터치 액션 버튼은 대사가 떠 있어도 바로 액션을 실행하며, 같은 입력이 대사도 함께 넘깁니다. `Z/Enter`는 표시 중인 대사를 완성하거나 다음 대사로 넘기며, `X/Esc`는 열린 창이나 대사를 먼저 닫습니다. 도감 상세에서는 목록으로 돌아가고, 플레이 화면에 닫을 대사가 없을 때 시작 화면으로 돌아갑니다. 배경화면 모드에서는 해당 모드부터 해제합니다. 포획 결과와 보물상자 카드는 `X/Esc` 외에 `Z/Enter/Space`로도 닫고, 조작법·도감 상세는 `X/Esc`로 닫습니다.

장비는 대부분 2단계까지이며 작살줄만 15단계까지 올라갑니다. 정해진 두 단계 값은 그대로이고 그 위로는 단계마다 22%씩 비싸집니다. 작살줄을 끝까지 올리는 데 모두 26,390코인이 들며, 그때부터 **상어를 작살로 잡아 수족관에 넣고 팔 수 있습니다**(마리당 150코인). 그 전에는 작살이 튕겨 나갑니다. 메갈로돈과 잠수함은 어떤 단계에서도 구경만 합니다. 도감을 다 채우는 칭호 조건에는 상어가 들어가지 않습니다.

하늘(`T`)은 물빛만 바꾸는 것이 아니라 **새로 만드는 바다에 드는 무리**도 정합니다. 달밤에는 발광어·아귀·오징어·해파리가 늘고 얕은 물의 무리가 줄며, 일출에는 그 반대입니다. 거북처럼 따로 적어 두지 않은 무리는 하루 내내 같은 수입니다. 이미 만들어진 바다는 하늘을 바꿔도 그대로이고, 시작하거나 `N`으로 새 바다를 만들 때 반영됩니다.

배는 움직이는 쪽으로 뱃머리를 돌리고, 낚싯줄은 언제나 뱃고물의 낚싯대 끝에서 떨어집니다. `Tab`으로 배에서 내리면 그 자리에 배가 그대로 떠 있고 내릴 때 보던 방향을 유지합니다. 다시 타면 그 방향에서 출발하며, 새 플레이를 시작하면 세워 둔 배는 사라집니다. 세워 둔 배는 잠수 중에만 보이고 시작 화면에는 나타나지 않습니다.

`Ctrl`·`Alt`·`Meta` 조합과 문자 조합 중인 입력은 게임 단축키로 처리하지 않습니다. `Shift` 가속은 계속 사용할 수 있습니다.

다이얼 가운데는 이동하지 않는 영역이며, 손을 떼거나 화면을 회전하면 중앙으로 돌아옵니다. 메뉴와 도감에서는 다이얼로 한 항목씩 이동합니다. 가로 화면은 다이얼·메뉴·액션을 좌우로 나란히 배치하고, 모든 버튼의 터치 영역은 최소 44px를 유지합니다.

입질 중에는 알림이 떠 있어도 포획 버튼을 누르면 바로 챔질합니다. 화면 크기 변경은 진행 중인 바다와 수심을 유지하며, 새 바다는 메뉴에서 새 게임을 시작하거나 `N`·`더 보기 → 새 바다`로 생성합니다.

수집 기록은 이 브라우저에 자동 저장됩니다. 손상된 저장 필드는 복구하고 정상 기록은 유지하며, 페이지를 닫거나 숨길 때 대기 중인 기록을 저장합니다. 수정 항목과 검증 결과는 [게임 검증 문서](docs/verification.md)에 정리했습니다.

## 수족관·상점·가방·하트

포획한 일반 생물과 희귀 생물은 수족관에 따로 쌓입니다. `A` 또는 시작 메뉴·모바일 더 보기의 수족관을 열고 항목을 선택하세요. ←/→ 또는 다이얼 좌우로 판매 수량을 바꾸고 Z/Enter·판매 버튼으로 확정합니다. 전체 판매도 확인을 거칩니다. X/Esc·뒤로는 확인을 취소한 다음 목록을 닫습니다. 희귀 개체는 일반 시세의 3배이며, 판매해도 누적 포획·도감·첫 포획 수심·칭호·외형 해금은 유지됩니다.

`S` 또는 더 보기 → 장비 상점에서 모은 코인을 사용합니다. **장비 / 소모품 / 외형** 탭은 ←/→, 상품은 ↑/↓, 페이지는 Q/E로 이동합니다. 터치에서는 탭·목록·페이지 버튼이나 다이얼을 사용합니다. 구매 확인창에는 사용 역할, 구매 전후 효과, 적용 시점과 해금 조건을 표시합니다. 긴 설명은 ↑/↓·Q/E·휠·드래그·스크롤 버튼으로 읽을 수 있습니다.

성능 장비는 최대 2단계이며 구매 즉시 적용합니다. 잔액 부족·최대 단계·보유 한도·사용 조건은 확정할 때 다시 확인합니다. 취소하거나 조건이 맞지 않으면 코인과 아이템을 사용하지 않습니다.

| 생물 탐지기 | 400 / 900 | 1단계 반경 180 내 가장 가까운 포획 가능 생물, 2단계 반경 300 내 미포획 어종 우선 |
| 더 큰 낚싯배 | 700 / 1600 | 배가 롱십 → 모터요트로 바뀌고 이동 속도 +20% / +40% |

탐지기는 0.5초의 플레이 시간마다 자동 갱신합니다. 잠수부·내려놓은 낚싯줄 끝·줄을 던지기 전의 배가 탐색 중심입니다. 화면 안에서는 표식, 밖에서는 방향 화살표로 표시하며 미포획 어종은 색과 ?로 구분합니다. 이름·희귀 여부를 공개하거나 도감을 등록하지 않습니다. 상어·잠수함·메갈로돈을 제외하며 배경화면 모드에서는 표시하지 않습니다. 거리와 반경은 게임 내부 단위입니다.

**가방은 I 또는 더 보기 → 가방**으로 엽니다. 열면 바다가 멈추며 보유량과 사용 가능 여부를 확인할 수 있습니다. 제목 화면에서는 조회만 가능하고 게임오버에서는 사용할 수 없습니다.

| 소모품 | 가격 | 보유 한도 | 사용 방법 |
| --- | --- | --- | --- |
| 표적 미끼 | 60 / 1개 | 5개 | 한 번 이상 포획한 어종 선택 → 확인 |
| 비상 산소 캡슐 | 60 / 1개 | 3개 | 실제 회복량 확인 → 사용, 한 플레이 최대 3회 |

표적 미끼는 사용 지점 반경 160 안에 선택한 어종이 실제로 있어야 소비됩니다. 잠수 중에는 현재 위치, 낚시 중에는 조절 중인 낚싯줄 끝에 설치합니다. 60초 동안 범위 안의 해당 어종을 기본 이동 속도의 1.25배로 유인하며, 서식 수심·해저 생물 높이를 유지합니다. 도망·입질·회수 중인 생물에는 적용하지 않습니다. 동시에 하나만 설치하며 중첩·시간 연장은 불가능합니다. 생성 수·희귀 확률·낚시 대상 선택은 그대로이며, 메갈로돈을 부르는 특별 미끼(M)와 별개입니다.

산소 캡슐은 살아 있고 체력이 부족한 잠수부만 사용합니다. 하트 한 칸을 회복하되 최대 체력을 넘지 않으며, 반 칸만 부족하면 반 칸만 회복합니다. 사용 성공 후 가방을 닫고 이전 플레이·일시정지 상태로 돌아갑니다.

| 외형 | 가격 | 구매 조건 |
| --- | --- | --- |
| 노란 잠수복 / 기본 낚싯배 | 기본 제공 | 없음 |
| 검은 잠수복 | 300 | 없음 |
| 파란 잠수복 | 450 | 없음 |
| 진주 잠수복 | 900 | 포획 가능한 생물의 희귀 개체 1마리 이상 포획 |
| 민트 낚싯배 | 600 | 없음 |
| 황금 낚싯배 | 1,200 | 서로 다른 포획 가능 어종 10종 이상 포획 |

외형은 한 번 구매하면 즉시 착용하고, 보유 외형과 기본 외형은 무료로 전환합니다. 잠수복의 몸통·그늘, 배 선체의 기본색·그늘·밝은 면만 바뀌며 성능에는 영향이 없습니다. 배 도색은 조종 중인 배와 잠수 후 수면에 남은 배에 함께 적용됩니다. 해금은 누적 포획 기준이라 판매해도 유지되며, 이미 보유한 외형은 다시 잠기지 않습니다.

체력은 하트 5칸으로 시작합니다. 상어 충돌은 반 칸, 메갈로돈 충돌은 한 칸을 소모하며 피격 후 약 1초간 추가 피해를 받지 않습니다. 상자는 한 번만 하트 한 칸을 회복하고 기존처럼 특별 미끼를 해금합니다. 무엇을 받았는지는 포획 결과와 같은 카드로 보여 주며, 숨이 가득 차 있어 회복이 없었다면 그 줄은 적지 않습니다. 체력이 없으면 게임오버 화면에서 Z/Enter·다시 잠수로 재시작하거나 X/Esc·시작 화면으로 돌아갑니다.

| 상황 | 미끼 효과 | 캡슐 사용 횟수 |
| --- | --- | --- |
| 가방·상점 등 창 / 일시정지 / 페이지 숨김 | 남은 시간 정지 | 유지 |
| 화면 회전 | 위치 보정 후 유지 | 유지 |
| 잠수·낚시 역할 전환 | 유지 | 유지 |
| N 또는 더 보기 → 새 바다 | 종료, 소비 아이템 반환 없음 | 유지 |
| 새 플레이 / 게임오버 후 재시작 | 종료 | 0회로 초기화 |
| 게임오버 / 재접속 | 종료, 소비 아이템 반환 없음 | 다음 새 플레이부터 0회 |

장비·코인·어획물 재고·소모품 재고·누적 수집·외형 보유와 착용은 자동 저장됩니다. 현재 체력·활성 미끼·이번 플레이의 캡슐 사용 횟수는 저장하지 않습니다. 역할 전환·회전·창 전환·N은 체력을 회복시키지 않습니다.

수족관·상점·가방·확인창을 닫으면 원래 제목/플레이 화면과 일시정지 상태로 돌아갑니다. 짧은 가로 화면은 상품을 페이지로 나눕니다. 기존 저장 키 `atseadot.v4`와 `economyVersion: 1`을 유지하며, 없는 신규 항목은 미구매·재고 0·기본 배로 해석합니다. 손상된 필드만 복구하고 코인·기존 장비·판매 기록·검은 잠수복은 보존합니다. 이전 버전의 포획 재고 복구는 한 번만 수행하며 판매한 재고를 다시 채우지 않습니다.

단계별 검사와 화면·플레이 기록은 [상점 추가 아이템 검증](docs/verification.md#상점-추가-아이템-6종-2026-09-17)에 정리했습니다.

## Apple·Android 홈 화면 아이콘

`favicon.svg`의 픽셀 아트와 색상을 유지한 PNG 아이콘을 제공합니다. `index.html`과 `404.html`에 Apple 아이콘 및 웹 앱 매니페스트를 연결했습니다.

| 용도 | 크기 | 파일 |
| --- | --- | --- |
| Apple 기본·iPhone | 180×180 | `site/apple-touch-icon.png` |
| iPad | 152×152, 167×167 | `site/assets/icons/apple-touch-icon-{크기}x{크기}.png` |
| Android 일반 | 192×192, 512×512 | `site/assets/icons/android-chrome-{크기}x{크기}.png` |
| Android 마스크 적용 | 192×192, 512×512 | `site/assets/icons/android-chrome-maskable-{크기}x{크기}.png` |

[Apple의 홈 화면 아이콘 설정](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)과 [웹 앱 매니페스트 안내](https://web.dev/learn/pwa/web-app-manifest)를 기준으로 구성했습니다. 마스크 적용용 원본은 물고기를 중앙 안전 영역 안에 배치해 원형이나 둥근 사각형으로 표시할 때도 잘리지 않도록 했습니다. 모든 PNG는 불투명 배경이며, 모서리는 기기에서 처리합니다.

원본 SVG를 수정한 뒤 다음 명령으로 PNG를 다시 생성합니다. 마스크 적용용 도안은 `site/assets/icon-maskable.svg`에서도 함께 수정합니다.

```sh
npm run icons:generate
```

생성된 PNG를 배포 파일에 포함하므로 일반 빌드에서는 다시 생성하지 않습니다. 홈 화면에 추가하면 `At Sea DOT` 이름과 아이콘을 사용하고 `/`에서 게임을 엽니다. 이 설정은 아이콘·실행 정보이며 오프라인 캐시는 포함하지 않습니다.

## Cloudflare Workers: Git 연동

이 프로젝트를 GitHub 또는 GitLab 저장소에 올리고 Cloudflare 대시보드의 **Workers & Pages → Create application → Import a repository**에서 연결합니다.

| 설정 | 값 |
| --- | --- |
| Framework preset | None |
| Production branch | 저장소의 기본 브랜치, 예: `main` |
| Root directory | 저장소 루트, 하위 폴더 지정 없음 |
| Build command | `npm run build` |
| Deploy command | `npx wrangler deploy` |
| 환경 변수 | 필요 없음 |

`wrangler.jsonc`의 프로젝트 이름은 `atseadot`이며 `assets.directory`가 배포 결과물인 `site/`를 가리킵니다. 따라서 Cloudflare의 기본 Workers 배포 명령인 `npx wrangler deploy`도 별도 인자 없이 정적 사이트를 찾습니다. 다른 이름의 프로젝트를 사용하면 이 파일의 `name`도 해당 이름으로 맞춥니다.

## Cloudflare Workers: 직접 배포

Wrangler로 업로드할 때는 먼저 로그인합니다.

```sh
npx wrangler login
npm run deploy
```

`deploy`는 검증 후 `site` 폴더를 `wrangler.jsonc`에 지정된 Worker의 정적 자산으로 업로드합니다. Cloudflare 빌드 단계처럼 검증이 이미 끝난 환경에서는 `npx wrangler deploy`를 사용해 검증을 중복 실행하지 않을 수 있습니다.

## 배포 확인

- `/`에서 게임 제목 화면이 표시되는지 확인합니다.
- 방향키와 Z/Enter로 잠수·낚시를 시작하고, `G`로 도감을 엽니다.
- `/atseadot.html`과 `/atseadot`이 `/`로 이동하는지 확인합니다.
- 없는 주소에서는 404 안내가 표시됩니다.
- 언어·도감·수집 기록은 브라우저의 `localStorage`에 저장됩니다. 로컬 주소, 미리보기 주소, 실제 서비스 도메인은 각각 별도의 저장 공간을 사용합니다.

배포 파일에서 다운로드 시 삽입된 AdGuard 스크립트를 제거했습니다. 게임에 필요한 CSS, JavaScript, 아이콘은 모두 같은 사이트에서 제공합니다.
