# 바다 아케이드 오디오

## 제작 방식과 출처

`site/assets/js/audio.js`에서 Web Audio API로 직접 합성합니다. 외부 음원, 녹음,
샘플, 기존 곡의 멜로디를 가져오지 않으며 음원 서비스나 추가 라이브러리도 사용하지
않습니다. 음악의 음표·진행과 효과음 패턴을 소스 코드에 함께 보관합니다.
외부 음원에 따른 이용료, 출처 표시 조건, 별도 음원 라이선스 의존성은 없습니다.

음악은 100 BPM, 4/4박자, 32마디의 76.8초 루프입니다. 사각파 멜로디,
삼각파 베이스, 사인파 킥과 합성 노이즈 타악기를 사용합니다. 제목·수면은 밝게
재생하고, 잠수 수심 0~900m에 따라 음악의 저역 통과 필터를 부드럽게 조절합니다.
포획 카드·도감·상점·소리 설정에서는 음악을 설정 볼륨의 40%로 낮춥니다.

파도와 물방울은 별도의 고정 시드 난수로 만든 노이즈입니다. 오디오 제작이나
재생이 게임의 생물 생성, 포획 성공률, 희귀 확률에 사용하는 난수를 소비하지 않습니다.
환경음은 효과음 볼륨을 따릅니다. 출력에는 과도한 소리 겹침을 줄이는 압축기를 둡니다.

## 피해·특수 개체 변주

- 실제 라이프가 깎일 때 짧은 충격 노이즈와 하강음을 냅니다. 음악은 설정 볼륨의
  55%로 부드럽게 낮추고 2.4초 동안 하강형 긴장 멜로디·낮은 베이스로 변주합니다.
  무적 시간 중 접촉에는 재발동하지 않으며 사망 시에는 기존 게임오버 효과음을 냅니다.
- 메갈로돈은 화면에 처음 들어올 때 낮은 경고음을 내고, 보이는 동안 단조 느낌의
  멜로디·낮은 베이스·추가 킥으로 음악을 바꿉니다.
- 잠수함은 화면에 처음 들어올 때 소나음을 내고, 보이는 동안 사인파 아르페지오로
  음악을 바꿉니다. 도감에 이미 기록된 종이어도 새로운 개체라면 등장음을 냅니다.
- 음악 우선순위는 **피해 → 메갈로돈 → 잠수함 → 기본 음악**입니다. 두 특수 개체가
  동시에 처음 보이면 메갈로돈 등장음만 냅니다. 등장음은 개체별 한 번이며 화면 재진입,
  창 닫기, 음소거 해제 시 뒤늦게 다시 울리지 않습니다.
- 피해 변주 시간은 일시정지·설정창·도감·탭 숨김 동안 멈춥니다. 특수 개체가 화면에서
  사라지거나 피해 시간이 끝나면 기존 박자와 32마디 진행을 유지한 채 기본 음악으로
  돌아갑니다. 효과음 볼륨이 0이어도 배경음악의 변주는 유지합니다.

## 조작과 저장

- 제목 메뉴의 **소리 설정**, 모바일 **더 보기 → 소리 설정**, 또는 `O`로 설정창을 엽니다.
- `U`는 전체 음소거를 전환합니다. 거래 확인창·게임오버에서도 사용할 수 있습니다.
- 설정창은 위·아래로 항목 선택, 좌·우로 볼륨 조절, Enter/Z/Space로 항목 실행,
  X/Esc로 닫기입니다. 터치로 음소거와 각 볼륨의 −/+를 직접 누를 수도 있습니다.
- 기본값은 음소거 해제, 음악 30%, 효과음 50%이며 0~100%를 10% 단위로 조절합니다.
- 설정은 `atseadot.audio.v1`에 별도로 저장합니다. 저장 실패는 게임 진행을 막지 않으며,
  손상되거나 범위를 벗어난 설정은 기본값으로 복구합니다.
- 설정창을 열면 플레이 이동·피해·포획을 멈춥니다. 창을 닫으면 기존 역할, 일시정지,
  포획 카드와 거래 확인 상태를 유지합니다.

## 재생 수명과 인터페이스

첫 클릭·터치·키 입력 이전에는 AudioContext나 음원을 생성하지 않습니다.
일시정지·탭 숨김·창 포커스 상실·페이지 이탈·음소거 시 스케줄러와 재생 중이거나
예약된 소리를 모두 정리합니다. 일시정지를 해제하거나 화면에 복귀해도 다음 사용자
입력까지 자동으로 재생하지 않습니다. 브라우저가 오디오를 중단한 경우에도 다음
입력에서 재개합니다. Web Audio 미지원·초기화 실패·활성화 거절 시 게임은 계속 동작합니다.

`createAtSeaAudio()`는 다음 인터페이스를 제공합니다.

| 메서드 | 용도 |
| --- | --- |
| `unlock()` | 사용자 입력에서 오디오 생성·활성화. 중복 호출은 하나의 초기화를 공유 |
| `setScene({depth, overlay, paused, damaged, encounter})` | 수심·창·일시정지·피해·특수 개체 반영. `encounter`는 `normal` / `mega` / `sub`. 자체적으로 재생을 재개하지 않음 |
| `playEffect(name)` | 의미 있는 게임 이벤트의 효과음. 재생하지 못하면 `false` 반환 |
| `setSettings({muted, music, effects})` | 설정 갱신·저장. 음소거 해제 후 활성화는 별도 입력 필요 |
| `suspend()` | 예약음·노드·스케줄러 정리 |
| `getSettings()` / `getState()` | 설정 사본 및 지원·재생·노드 상태 확인 |

효과음은 메뉴 이동·확인·취소, 작살, 투척·회수·입질, 일반·희귀 포획, 상자,
거래 성공·실패, 피해·회복·게임오버에 연결합니다. 이미 발사된 작살, 무효 피해,
체력이 가득 찬 회복 등 실제 결과가 없는 요청에는 효과음을 내지 않습니다.
동일 효과음은 80~140ms 간격을 제한하고 환경음을 포함한 효과음 동시 발음은 최대 16개,
전체 발음은 최대 64개입니다. 완료된 음원 노드는 연결을 해제합니다.

## 검증 결과 — 2026-10-06

- `npm run build`: 피해·특수 개체 확장 후 오디오·게임 구문 검사 및 자동 테스트 127개 통과.
- 오디오 테스트 18개: 입력 전 무재생, 동시 활성화, 저장 복구, 독립 볼륨,
  수심·창 전환, 예약음 정리, 비동기 재개 취소, 미지원·실패 복구, 연타·발음 제한,
  32마디 반복, 실제 게임 이벤트, 보물 카드·거래·게임오버 설정 접근, 모바일 터치 영역 검증.
- 추가 테스트에서 실제 상어 충돌, 피해 시간 만료·중단, 개체별 등장음 중복 방지,
  음악 우선순위와 효과음 0% 시 음악 변주 유지, 기본 음악 복귀를 확인했습니다.
- 로컬 Chrome: 초기 무재생, 실제 키 입력 후 재생, 일시정지·재개,
  음소거의 새로고침 후 복원, 모바일 더 보기 진입, 10% 볼륨 변경 확인.
- Chrome에 blur/focus·visibility 이벤트를 전달해 복귀 후 무재생을 확인하고,
  다음 실제 키 입력에서 재생이 재개됨을 확인했습니다.
- 로컬 Chrome의 실제 게임 객체로 상어 충돌 → 피해 변주 → 시간 만료,
  잠수함 → 메갈로돈 → 피해 우선순위 → 기본 음악 복귀를 확인했습니다.
- Chrome의 402×844 세로·844×390 가로 화면에서 한국어·영어 설정창 배치 확인.
  모바일 뷰포트 검증이며 실제 iOS Safari·Android Chrome 검증을 대신하지 않습니다.
- 실제 Chrome `OfflineAudioContext`로 세 변주를 포함한 78초 렌더링: 최대 진폭 0.228,
  NaN/무한대 0개, 루프 경계 RMS 0.0227. 클리핑이나 무음 루프 경계가 없고
  중단 후 예약음·스케줄러·노드가 정리됨을 확인했습니다.
- 브라우저 런타임 오류 없음. 실제 스피커 청취와 iOS·Android 기기에서의 음색,
  루프 경계 청감, 앱 전환 후 재개는 추가 수동 확인이 필요합니다.

오프라인 렌더링은 개발 서버를 연 브라우저에서 아래와 같이 재현할 수 있습니다.

```powershell
npx --yes agent-browser --session audio-check open http://127.0.0.1:8788
Get-Content scripts/verify-audio-browser.js -Raw -Encoding utf8 | npx --yes agent-browser --session audio-check eval --stdin
npx --yes agent-browser --session audio-check close
```
